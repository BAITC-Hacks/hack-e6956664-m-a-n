# Fullstack Node.js Developer — приложение и интеграция

## Реализовано

- Единый Node.js сервер на стандартных модулях, без установки npm-пакетов.
- Чтение полного CSV из `../data/contractors.csv`, включая pipe-разделённые массивы и многострочные/кавыченные описания.
- `GET /api/meta` для городов, категорий, форматов, языков и границ календаря.
- `POST /api/recommendations`: валидация запроса, три исхода, точная проверка календаря, бюджета, формата и опциональных условий.
- Стабильный порядок: цена по возрастанию, затем ID; максимум три карточки.
- 1–2 проверяемых предложения в карточке, пояснение числа кандидатов/причин отказа и флаги synthetic/imputed.
- Интерфейс и быстрые кнопки основных demo-запросов в `../public/`.

## Запуск

Из корня проекта: `node server.js`, затем открыть `http://localhost:3000`.

```text
POST /api/recommendations
Content-Type: application/json

{
  "city": "Алматы",
  "date": "2026-10-07",
  "eventFormat": "свадьба",
  "category": "Ведущий",
  "budgetKzt": 2000000,
  "language": "",
  "maxHours": null
}
```

Контракт ответа и причин исключения находится в [общем README](../README.md). Каталог — `../data/contractors.csv`.
